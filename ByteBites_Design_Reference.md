# ByteBites Reference File

## About This Project
You are building the backend logic for a campus food ordering app called ByteBites
using Python classes and simple algorithms.

## Project Scope
Do not add authentication logic, a database layer, or any features not described 
in the spec.


## Behavioral Instructions

- Implement exactly four core classes: Customer, MenuItem, Menu, and Order.
- Use Python and straightforward object-oriented programming.
- Customer stores a name and purchase history.
- MenuItem stores a name, price, category, and popularity rating.
- Menu stores a collection of MenuItem objects.
- Menu supports filtering by category and sorting by popularity.
- Order stores selected MenuItem objects and calculates their total cost.
- Use clear constructors and descriptive method names.
- Keep the design beginner-friendly and avoid unnecessary classes.
- Validate menu item prices and handle empty orders correctly.
- Use Python's built-in lists and sorting tools where appropriate.
- Follow the specification and UML diagram instead of inventing new features.
- Include small examples and tests to verify the implementation.
